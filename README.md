## О проекте

QSGoodix - модуль ядра FreeBSD для сенсорных экранов Goodix, подключённых по I2C и описанных в ACPI. 

> [!WARNING]
> **Протестировано:** GDIX1002, GT9110, сетка 3840x2190, 10 касаний.
>
> **Не проверялось:** другие чипы Goodix с тем же протоколом (GT911, GT912, GT927, GT928, GT967, GT9147, GT9271). Для них нужны правки в `gt_acpi_ids` и `gt_identify`. GT1151, GT5663, GT5688, GT917S и GT9286 дополнительно требуют чтения конфига по адресу 0x8050. Отчёты о работе на другом железе приветствуются через issues.

## Возможности

**Мультитач через evdev**
 - До 10 одновременных касаний, протокол ABS_MT (slots)

**Прерывание или опрос**
 - Если прерывание недоступно или не срабатывает, драйвер опрашивает контроллер: медленно в простое, быстро при касании

**Сброс контроллера через GPIO**
 - Линии INT и RST берутся из `_CRS`. Если контроллер не отвечает на шине (при старте, после resume или после серии ошибок), драйвер сбрасывает его через RST

**Suspend/resume**
 - Если найдены линии GPIO, контроллер усыпляется при suspend и будится при resume

**Настройка осей и панели**
 - invert_x, invert_y - зеркалирование осей
 - swap_xy - обмен осей X и Y (только до загрузки модуля)
 - x_override, y_override - размер сетки чипа по осям X и Y (до swap_xy) вместо значения из конфига
 - poll_active_hz, poll_idle_hz - частота опроса
 - suspend_sleep - усыплять контроллер при suspend
 - debug - маска отладки: 1 init/power, 2 ошибки шины, 4 отчёты о касаниях

Все параметры задаются в `/boot/loader.conf` как `dev.goodix_acpi.0.<имя>="значение"`. `swap_xy`, `x_override` и `y_override` действуют только при загрузке модуля, остальные можно менять на лету через `sysctl dev.goodix_acpi.0`.

## Сборка / Запуск

**FreeBSD**

```
doas git clone --depth 1 --filter=blob:none --sparse -b releng/$(freebsd-version -k | cut -d- -f1) https://git.FreeBSD.org/src.git /usr/src
doas git -C /usr/src sparse-checkout set sys

make
doas kldload ig4 ./QSGoodix.ko
```
